Polish release: smoother menus, a calmer loading screen, and a tidier composer.

### What's new
- **Menus and dialogs open smoothly.** A short fade-and-scale on menus, popovers and dialogs (off when your Mac is set to reduce motion).
- **Faster first open.** The command palette and the Settings window are prepared in the background, and fonts and image connections are warmed up, so the first Cmd+K or Cmd+, is instant.
- **A loading screen that matches.** Launching or reloading no longer flashes black: you get your theme with the Exiter mark. Spinners and the top progress bar use the neutral palette instead of X's blue.
- **"See new posts" / "Show N posts" button.** Restyled as a clean floating button with an arrow icon that stays on one line at any count.
- **Sign-in screen.** The login card, fields and buttons now use the same corners, borders and colours as the rest of the app.
- **Composer corners.** The "What's happening?" box now uses exactly the same corner radius as the buttons, and follows the Corner radius setting.
- **Black spinners.** Loading spinners use the dark foreground colour instead of X's blue.
- **Fix:** Geist now actually loads inside X (the earlier build silently fell back to the system font).

### Updating
Exiter updates itself: macOS through Sparkle, Windows and Linux (AppImage) through the built-in updater. Use **Check for Updates…** to check now.

### Downloads
- **macOS** (Apple Silicon and Intel): `Exiter-0.2.0-mac-universal.dmg`. Signed and notarized.
- **Windows** (x64): `Exiter-0.2.0-win-x64.exe`. Not code-signed; SmartScreen will warn.
- **Linux** (x64): `Exiter-0.2.0-linux-x86_64.AppImage` or `Exiter-0.2.0-linux-amd64.deb`.

The Windows and Linux builds have not been tested on those systems yet. Checksums are in `SHA256SUMS.txt`.
