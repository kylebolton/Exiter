First public release of Exiter, a quiet desktop app for X.

### Highlights
- A clean, minimal interface in light and dark, with an icon rail that adapts to the window width.
- **Command palette** (Cmd/Ctrl+K): jump to pages, start a post, refresh, change settings, search X.
- **Refresh** with Cmd/Ctrl+R or the header button; offline recovery reconnects by itself.
- **Settings** for theme, accent, font, text size, zoom, feed width, density, and what to hide (promoted posts, right column, suggestions, floating chat, counts).
- Menu bar icon, global shortcuts, launch at login.
- **Automatic updates**: Sparkle on macOS, electron-updater on Windows and Linux.

### Downloads
- **macOS** (Apple Silicon and Intel): `Exiter-0.1.0-mac-universal.dmg`. Signed and notarized.
- **Windows** (x64): `Exiter-0.1.0-win-x64.exe`. Not code-signed; SmartScreen will warn.
- **Linux** (x64): `Exiter-0.1.0-linux-x86_64.AppImage` or `Exiter-0.1.0-linux-amd64.deb`.

The Windows and Linux builds have not been tested on those systems yet. Checksums are in `SHA256SUMS.txt`.

Exiter is unofficial and not affiliated with X Corp.
