## Desktop notifications

Enable **Settings → Notifications → Desktop notifications** to receive a quiet alert when X’s unread count increases while Exiter runs in the background. Clicking an alert opens Notifications. Use **Send test** to check delivery.

## Interface improvements

- Settings now has section shortcuts, keeps keyboard focus when values change, and asks you to confirm before resetting preferences.
- The sidebar has a clearer active state and waits for a click to be completed before navigating.
- The command palette has smoother open and close transitions, a close button, and keyboard focus return. Navigation and refresh respect the system’s reduced-motion setting.
- Refresh shows when it’s busy and leaves typing uninterrupted. Offline retries return to the page you were trying to open.
