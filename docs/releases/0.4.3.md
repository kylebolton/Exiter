## Keep your place

- Continue reading from the command palette. Exiter remembers your reading position locally for each X account.
- Use Option/Alt+Up or Down to move through posts and Enter to open a thread. Going back restores your place and keyboard focus when the post is available.
- Pin X Lists and searches to the palette. Reopening Exiter from the tray keeps the current view.

## Interface improvements

- Slow timelines show a themed loading placeholder. Refresh reports whether new content appeared.
- The palette highlights the selected command. Like, repost and bookmark animations play when an on-screen post changes state. The new motion respects reduced motion.
- New Post uses the in-page composer when X is ready. The modal has a single field focus outline and a clearer disabled Post button.
- Exiter accepts direct links through its registered `exiter://` scheme. The README explains optional macOS routing for ordinary X links.
