Search, refresh and navigation polish.

### What's new
- **Search, restyled.** The suggestions dropdown is now a proper popover (it used to be see-through), with compact rows, muted handles and neutral "Recent" / "Clear all". The search bar has a single light outline and a soft focus ring instead of a doubled dark stroke.
- **Explore and search results.** Headings, news and trends use the same type scale as the rest of the app, with muted meta lines and hover states.
- **Faster navigation.** Cmd+K searches and jumps no longer reload the page. Sidebar links respond on press. Exiter reopens on the page you left, and refreshes when you come back after a minute or more away.
- **Refresh that finishes.** Refreshing waits for new posts to arrive, then scrolls to the top. The refresh icon spins only while it works.
- **Small motions.** Page changes ease in, the selected tab's underline grows in, buttons respond to a press, likes and bookmarks pop, and the new-posts count ticks when it changes. All of it is off when your Mac is set to reduce motion.
- **New-posts button.** Avatars in the "Show N posts" button are a tidy overlapped stack, with a press state and a focus ring.

### Updating
Exiter updates itself: macOS through Sparkle, Windows and Linux (AppImage) through the built-in updater. Use **Check for Updates…** to check now.

### Downloads
- **macOS** (Apple Silicon and Intel): `Exiter-0.2.1-mac-universal.dmg`. Signed and notarized.
- **Windows** (x64): `Exiter-0.2.1-win-x64.exe`. Not code-signed; SmartScreen will warn.
- **Linux** (x64): `Exiter-0.2.1-linux-x86_64.AppImage` or `Exiter-0.2.1-linux-amd64.deb`.

The Windows and Linux builds have not been tested on those systems yet. Checksums are in `SHA256SUMS.txt`.
