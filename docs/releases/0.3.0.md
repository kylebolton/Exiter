Menus, the compose window and the new-posts row now match the rest of the app.

### What's new
- **Compose window.** The text box has the same outline and focus ring as the home composer. Drafts is a quiet button, the Post button is the right size, and the character ring is neutral instead of blue.
- **"Save post?" sheet.** Restyled as a proper card with matching Save and Discard buttons, and it opens with the same short animation as menus.
- **More menu.** Line icons in one aligned column, a soft keyboard-focus highlight, and no stray divider.
- **"Show N posts" row.** The row in your timeline is a quiet button with an arrow and a hover state instead of blue text.

### Updating
Exiter updates itself: macOS through Sparkle, Windows and Linux (AppImage) through the built-in updater. Use **Check for Updates…** to check now.

### Downloads
- **macOS** (Apple Silicon and Intel): `Exiter-0.3.0-mac-universal.dmg`. Signed and notarized.
- **Windows** (x64): `Exiter-0.3.0-win-x64.exe`. Not code-signed; SmartScreen will warn.
- **Linux** (x64): `Exiter-0.3.0-linux-x86_64.AppImage` or `Exiter-0.3.0-linux-amd64.deb`.

The Windows and Linux builds have not been tested on those systems yet. Checksums are in `SHA256SUMS.txt`.
